# Gotchas

Jede Zeile ist ein Fehler, den wir einmal gemacht oder knapp vermieden haben. Spalten: Symptom, Ursache, Regel, Wächter-Idee, Geltung und der Test, der den Rückfall im Referenz-Agenten fängt.

Ein Test hat immer eine Gegenprobe: dieselbe Prüfung, gegen eine nachgebaute alte, fehlerhafte Variante gerichtet, muss rot werden. Die alte Variante ist ein Modell des Fehlers, nicht der Original-Code. `test/kit.test.ts` prüft, dass jede Testangabe hier auf einen existierenden Test mit Gegenprobe zeigt. „Regel ohne Test“ heißt: Die Regel betrifft Messarbeit oder Arbeitsweise und lässt sich im Code des Referenz-Agenten nicht festhalten.

**Geltung:** *neutral* gilt für jede Plattform, *Vapi* nennt Feldnamen oder Verhalten von Vapi; die Idee dahinter überträgt sich meist trotzdem.
